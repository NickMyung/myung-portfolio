# Paquete de presentación del portafolio

**Leer primero:** [Guía de lectura y evaluación](guia-de-revision.html), [texto en español](GUIA_DE_REVISION.md) y [English review guide](review-guide.html).

Autor del portafolio: Nick Soto Conde. Fecha de referencia: 1 de noviembre de 2026.

## Cómo usarlo

1. Descomprimir el ZIP conservando todas las carpetas.
2. Abrir index.html en un navegador: el índice visual en inglés funciona sin iniciar servidores.
3. Para presentar, abrir las imágenes PNG originales desde desktop/ y mobile/. La imagen desktop/00-full-page.png permite revisar la página completa.
4. Mostrar los ejemplos de code/ y consultar code-excerpts.md para copiar el código. Cada fragmento indica archivo y líneas de origen.
5. La carpeta source/ contiene una copia del código de la aplicación y su configuración, sin node_modules, archivos .env ni datos de Git.

## Contenido

- 14 capturas de escritorio, además del panorama completo.
- 7 vistas móviles.
- 8 ejemplos de código en PNG, HTML y texto.
- Código fuente y manifiesto SHA-256 para verificar la integridad de los archivos.

## Recorrido sugerido ante el evaluador

Presentar la identidad mecatrónica y los tres pilares; explicar la selección equilibrada de proyectos; mostrar un caso por área; justificar fondo, paleta y tipografía con los fragmentos de código; cerrar con adaptación móvil y el modelo interactivo.

Las capturas son reales, tomadas de una compilación local del estado actual de trabajo. Los textos y estados de la aplicación no se reescribieron para las imágenes. El modelo 3D se abrió y se mantuvo pausado. Las vistas son capturas de pantalla representativas; las secciones largas continúan fuera del encuadre.

Este material documenta el diseño y su implementación. No constituye validación independiente de resultados profesionales o científicos, rendimiento clínico ni una certificación de accesibilidad.
